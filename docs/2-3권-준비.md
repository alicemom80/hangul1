# 2권·3권 만들기 (그림과 노래만 넣으면 돼요)

앱 코드는 1·2·3권이 **하나**예요. 어느 권을 만들지는 `VOLUME`(1·2·3)으로 정하고, 권마다 다른 것은 `src/data/zoo2.js`, `zoo3.js`에 들어 있어요.
이 문서는 "무엇을 어디에 넣으면 되는지"만 적은 사용 설명서예요(기획 문서가 아니에요).

## 1. 권별 동물과 글자

| 권 | 글자 | 동물 (그림 파일 이름 = key) |
|---|---|---|
| 2권 (6마리) | ㅁ ㅂ ㅈ ㅊ ㅌ ㅍ | 미어캣 `meerkat`, 반달곰 `bear`, 조랑말 `pony`, 치타 `cheetah`, 타조 `ostrich`, 펭귄 `penguin` |
| 3권 (7마리) | ㄹ ㅇ ㄲ ㄸ ㅃ ㅆ ㅉ | 라마 `llama`, 여우 `fox`, 꽃사슴 `deer`, 딱따구리 `woodpecker`, 뻐꾸기 `cuckoo`, 쌍봉낙타 `bactrian`, 찌르레기 `starling` |

동물을 바꾸고 싶으면 `zoo2.js` / `zoo3.js`의 `ANIMALS`(이름·key)와 `VERSES`(가사)를 같이 고치세요. `npm run check:2`가 서로 안 맞는 곳을 알려 줘요.

## 2. 넣을 파일 (권마다)

| 무엇 | 어디에 | 규격 |
|---|---|---|
| 동물 그림 | `public/images/characters/<key>.webp` | 배경이 투명한 webp, 키 450~510px 정도, 1권 그림과 같은 느낌 (동물만 한 마리씩 잘라서) |
| 노래 | 2권 `public/audio/song2.mp3`, 3권 `public/audio/song3.mp3` | mp3. 1권은 69초(24줄) |
| 노래 배경 | 2권 `public/images/backgrounds/song-bg-2.webp`, 3권 `song-bg-3.webp` | 가로 1400px 정도 (1권 1400×788) |
| (선택) 노래 장면 소품 | `public/images/props/<이름>.webp` | `zoo2.js`/`zoo3.js`의 `SCENES`에 이름을 적으면 나와요 |

동물 그림 key는 1·2·3권이 **서로 겹치지 않아요**(그림 폴더가 하나라서).

## 3. 순서

1. 그림 넣기 → 노래 넣기 (위 표의 이름 그대로)
2. **박자 찍기**: `tools/박자찍기.html`을 브라우저로 열고(더블클릭), 노래 mp3를 고르고, 가사 줄이 시작될 때마다 스페이스(또는 분홍 버튼). 줄 수는 2권 24, 3권 28. 끝나면 "복사하기" → `zoo2.js`/`zoo3.js`의 `LINE_STARTS`, `LYRIC_END`를 바꿔 붙여요.
   - 박자를 아직 안 찍어도 앱은 돌아가요. 노래 길이에 맞춰 줄을 고르게 나눈 대략의 박자로 나와요(시험용).
3. **실제 가사에 맞추기**: 노래를 만들면서 가사가 달라졌으면 `VERSES`를 노래대로 고쳐요. (줄 수는 절마다 4줄 유지)
4. **점검**: `npm run check:2` (3권은 `check:3`). 빠진 그림·노래가 있으면 어디에 넣을지 알려 줘요.
5. **미리 보기**: `npm run dev:2` (3권은 `dev:3`) → 주소창에 나온 주소로 접속.
6. **음성(선택)**: `npm run voice:list:2` → `docs/음성 목록-2권.md`. 녹음 파일은 1권과 같은 폴더(`public/audio/voice`)에 넣어요. 없으면 휴대폰 기본 음성으로 읽어요.
7. **배포**: 새 GitHub 저장소(예: `hangul2`)를 만들고 같은 코드를 올려요 → 저장소 Settings → Secrets and variables → Actions → **Variables**에 `VOLUME` = `2` 추가 → Pages Source를 "GitHub Actions"로. (변수를 안 넣으면 1권이 배포돼요.) 빌드만 해 보려면 `npm run build:2`.

## 5. 3권만 알아 둘 점

- **ㅇ(여우)**: 첫소리가 "소리 없는 ㅇ"이라 코코의 안내 문구를 다르게 하고 싶으면 `src/audio/script.js`의 문장을 권별로 나눠야 해요. 지금은 다른 글자와 같은 문장이에요.
- **쌍봉낙타(ㅆ)**: 1권 낙타(ㄴ)와 헷갈리지 않게 혹이 두 개인 그림으로 그려 주세요.
- **받침 있는 첫 글자(꽃, 딱, 쌍)**: 빈칸 채우기에서 `□ㅗㅊ`처럼 받침이 보여요. 3~4세에게 어려우면 알려 주세요(받침을 가리는 방식으로 바꿀 수 있어요).
- **글자 쓰기**: ㅃ은 8획으로 가장 길어요. 아이 손으로 해 보고 너무 길면 쌍자음은 한 글자씩 쓰게 바꿀 수 있어요.
- **스티커북**: 7마리라 4칸×2줄로 나와요. 이름표 붙이기는 3+2+2마리로 세 판이에요.

## 6. 아직 안 된 것
- 앱 아이콘(`public/icons`)은 아직 숫자 앱 것이에요. 권마다 다르게 하려면 권별 아이콘 폴더가 더 필요해요.
- 권마다 음성 녹음(`public/audio/voice`)은 한 폴더를 같이 써요. 배포하면 다른 권 녹음도 같이 들어가 용량이 조금 늘어요. (동물 그림·노래·노래 배경은 다른 권 것이 빌드할 때 자동으로 빠져요.)
